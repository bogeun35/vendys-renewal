# 현대벤디스 — 좋은 회사의 하루

기업복지 홍보 홈페이지 공모전을 위한 디자인 프로토타입입니다. 기존 공식 사이트의 공개 콘텐츠와 브랜드 자산을 참고해 메인과 서비스별 상세, 회사소개, 콘텐츠, 상담 화면을 같은 디자인으로 구성했습니다. 운영용 결제·접수 시스템은 포함하지 않습니다.

## 실행

1. ZIP을 받았다면 전체 압축을 풉니다.
2. 프로젝트 폴더의 `START.bat`를 더블클릭합니다. 설치된 Google Chrome에서 메인이 열립니다.
3. BAT 실행이 제한된 환경에서는 Chrome에서 `dist/index.html`을 직접 엽니다.

별도 패키지 설치나 빌드는 필요 없습니다. `dist` 폴더 전체를 함께 보관하세요. HTML 파일 하나만 옮기면 스타일·이미지·내부 페이지 연결이 깨집니다. `START.bat`는 시스템의 기본 브라우저 설정을 변경하지 않습니다.

개발용 로컬 서버가 필요할 때만 Node.js 설치 환경에서 `node server.cjs`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 종료는 실행 창에서 Ctrl+C입니다.

## 화면 구성

- 메인: 직원의 하루, 기업복지 서비스, 담당자 운영 경험, 고객사례, 도입 안내
- 서비스별 독립 상세 12개: 식권대장·복지대장·단체선물대장·커피대장·배달대장·매점대장·푸드트럭대장·복지대장몰·퀵대장·의무교육대장·문자대장·사무기기대장
- 회사소개, 언론보도 목록·소개, 블로그 목록·콘텐츠
- 기업 도입·입점 문의, 소개서 신청의 선택 → 입력 → 완료 화면
- 식대 계산기 입력·결과 프레임 및 정책 안내 화면
- 데스크톱·모바일 메뉴, 서비스 분류, FAQ, 모션 중지 및 OS 모션 감소 대응

총 29개의 HTML 화면으로 구성되며 메뉴와 상담 동선은 프로토타입 내부 파일로 이동합니다. 기존 운영 사이트로 연결하거나 외부 신청 양식을 삽입하지 않습니다.

## 콘텐츠와 자산

서비스 소개·고객 사례의 참고 출처: https://sikdae.com/ 및 각 공식 서비스 페이지(2026-10-29 확인). 수치·혜택·이용 조건은 원본 기준일과 적용 조건을 함께 검토해야 합니다.
로고·서비스 사진·앱 화면: 공식 홈페이지 공개 원본. 아이콘: 공식 홈페이지와 동일한 Font Awesome 키트(사용자 회사 자산). 상세 URL은 ASSET-SOURCES.json 참조. 내부 기획 문서 원문, 사용자 정보 및 내부 시스템 자료는 배포본에 포함하지 않았습니다.
생성 이미지의 제작 기록은 IMAGE-PROMPTS.txt에 있습니다. 앱 화면이나 서비스 고유 아이콘은 공식 공개 자산과 구분합니다.
웹폰트·공식 아이콘 키트·일부 공식 소개 영상은 인터넷 연결을 사용합니다. 네트워크를 사용할 수 없으면 시스템 글꼴로 대체되거나 아이콘·영상이 표시되지 않을 수 있습니다. 따라서 이 파일 묶음은 완전한 오프라인 단일 HTML이 아닙니다.

## 동작 범위

정적 홍보 디자인 시안입니다. 상담·소개서·입점 문의의 입력 정보는 브라우저 화면에서만 사용하며 저장하거나 전송하지 않습니다. 완료 화면 역시 체험용입니다. 개인정보 대신 예시값으로 검토하세요.

계산기 화면은 디자인과 입력 흐름을 검토하기 위한 것으로, 운영용 절감액 산식이나 견적 기능을 연결하지 않았습니다. 뉴스·블로그 및 정책 화면에는 시안용 요약·구성이 포함되어 있으며 기사 전문이나 운영용 법률 문서를 대신하지 않습니다.

공식 앱 이미지는 공개 홈페이지 게시본으로 현재 앱 버전과 다를 수 있습니다. 기존 sikdae.com 운영 사이트에는 변경을 가하지 않았습니다.

## 검증

정적 검수 항목은 HTML별 H1, 중복 ID, 로컬 파일·앵커 연결, 이미지 대체텍스트, JavaScript 구문, 외부 페이지 이동·전송·저장 코드 유무입니다. 브라우저에서는 데스크톱·모바일 메뉴, 내부 상세 이동, 상담 선택·입력·완료, 계산기 및 모션 감소 상태를 확인합니다. 실제 전송·결제 검증은 이 프로토타입의 범위가 아닙니다.
